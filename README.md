

# Networked Communication for Decentralised Agents in Mean-Field Games

This repository contains the code for the experimental setups in 'Networked Communication for Decentralised Agents in Mean-Field Games'. 

## Requirements

To install requirements:

```setup
pip install -r requirements.txt
```

## Running

The experiments can be run with 

```
python main.py
```

This will cycle through the different experimental settings found in the paper. Other hyperparameters (as in Table 1) can be altered within the 'main' function in the main.py file. The code will save the final plots, as well as intermediate results for each trial and each algorithm.
